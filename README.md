# ArduPilot SITL UAV Simulation & MAVLink Control

A simulation-based UAV control project using ArduPilot SITL, MAVLink, Python, and Mission Planner.

## Project Overview

This project explores autonomous UAV control using ArduPilot Software-In-The-Loop (SITL).

Python scripts communicate with the simulated ArduPilot flight controller through MAVLink using the `pymavlink` library.

The project is being developed progressively, starting from basic communication and telemetry and moving toward autonomous flight control.

## Technologies Used

- Python
- pymavlink
- MAVLink
- ArduPilot SITL
- ArduCopter
- MAVProxy
- Mission Planner
- Ubuntu / WSL2
